# Azure-Image-Recognition-App

This project is a cloud-based image recognition web application built using Azure Computer Vision and Python. 
It allows users to upload an image and receive AI-generated insights such as object detection, labels, 
descriptions, and confidence scores. The goal of this project is to demonstrate practical skills in 
AI engineering, cloud development, and end-to-end solution design using Microsoft Azure services.

The application will be developed using:
- Python (FastAPI or Streamlit)
- Azure Computer Vision (AI service)
- Azure App Service (deployment)
- Optional: Azure Blob Storage for image handling

This project is part of my personal portfolio and preparation for future AI and cloud engineering roles.
Development begins in March 2026.
